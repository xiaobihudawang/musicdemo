# 黑盒测试用例

> 测试对象：音乐分享平台 (MusicDemo)
> 测试环境：Chrome / Edge 最新版，MySQL 8.0，JDK 17+

---

## 1. 用户注册

| 编号 | 测试项 | 操作步骤 | 预期结果 | 实际结果 |
|:----:|--------|----------|----------|:--------:|
| TC01 | 注册成功 | 填写用户名 `testuser`、密码 `123456`、昵称、邮箱，点击注册 | 提示注册成功，跳转到登录页 | |
| TC02 | 用户名重复 | 使用已存在的用户名再次注册 | 提示"用户名已存在" | |
| TC03 | 密码太短 | 填写密码 `123`（小于6位） | 前端提示"密码长度6-18位" | |
| TC04 | 必填项为空 | 不填用户名直接点击注册 | 前端提示"请输入用户名" | |
